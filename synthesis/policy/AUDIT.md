# Adversarial audit and scope

The requested stopping condition, no possible loopholes with irrefutable proof,
has not been reached. A finite audit cannot establish that condition. The checked
theorems establish their written propositions within the pinned checker; the
native experiments establish observed finite behavior. Neither proves that the
specification captures every aspect of the owner's RSI intent.

## Repaired findings

| Attack | Repair and evidence |
| --- | --- |
| Preload a useful rule and call the higher starting point better learning | Actual learning comparison requires identical rule flags and equal measured cold costs; independent specification law and a mutation that removes the knowledge check |
| Reuse training examples as validation or subsequent cycles | Public request checks structural uniqueness and cross-partition separation, including retention-task leakage; malformed experiment tests |
| Assert improvement using an input score or acceptance flag | Strict schema rejects those fields; actual comparison executes both policies; public execution-binding laws and independent full-report oracle |
| Enable a heuristic and trust its predicted answer | Every admitted expression retains an evaluator-bound certificate over all sixteen inputs |
| Change policy ordering by dropping awkward candidates | Universal rank involution, injectivity, surjectivity and reference refinement; finite public search checks |
| Manufacture budget credit, skip charges or run with zero quota | Actual search conservation/resume/zero laws, revision zero laws, and mutations of production operations |
| Install a policy other than the evaluated candidate | Installation laws and wrong-policy mutation |
| Inflate the recursive claim by accepting many tiny changes | Report accepted cost reduction and both branches' verification work; the recursive-gain flag compares reductions after successful held-out validation |
| Forge reference, claimed cost or one output row in replay | Proof-producing typed replay, universal soundness and canonical completeness, forged native packets and final-row/cost mutations |
| Always refuse and pass conditional soundness | Canonical replay completeness plus a positive witness; actual learning example must match the independent oracle |

## Open findings

1. Original universal grammar enumeration, exact visited-prefix, best-prefix and
   search status laws are still missing. Finite tests are not their replacement.
2. Arbitrary-byte parser/renderer round-trip and source-to-native correctness are
   not proved. Typed replay completeness closes only the typed boundary.
3. RV64/Sail refinement, satisfiable formal loading and boot/loading proof remain
   open. The stock pinned Lean executable fails before elaboration on this runner's
   process-executable lookup. No patched checker is used.
4. The new policy/learning system is not fully refined to an independent trace
   semantics. Rank, proposal, scoring, execution-binding, zero-budget and search
   accounting laws cover named properties; they do not prove all trace fidelity,
   retention or multi-cycle accounting properties universally. Native differential
   checks cover finite cases only. Public internal Data records can be constructed
   by Bend callers; arbitrary constructed profiles are not execution evidence.
5. Structural separation cannot prove no hidden prior exposure, unfamiliar task
   families, representative task sampling, or independent data custody. Policies
   inspect task structure and have human-written rule schemas. Only a finite
   learning-procedure choice is revised, not the evaluator or policy interpreter.
6. Equal logical caps do not guarantee matched physical effort. Infrastructure
   failures return an error without a complete partial work ledger. No experiment
   should count such a run as a zero-cost failure or accepted improvement.
7. No empirical calibration, uncertainty-reporting, human-intervention metric,
   evaluator-upgrade transition, or statistical multi-seed superiority protocol is
   implemented. The finite policy interpreter is deterministic. Their absence must
   not become a claim that the broader quality profile is satisfied.
8. Policy values cannot edit protected machinery, but this is not a security
   isolation theorem about a host agent with filesystem or tool access. A candidate
   checkout cannot independently approve its own contract. The existing external
   factory authority remains unchanged; the new manifest is a proposed review
   identity until separately adopted there.

Full release must remain incomplete while its original requirements are open.
New bounded learning observations do not discharge those requirements. A local
failure to find another accepted policy is a plateau in this finite proposal
space and allowance, not proof that no better learner exists.
